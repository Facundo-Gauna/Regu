# Documentos fuente (no incluidos en el repositorio)

Esta carpeta guarda **en tu máquina** los documentos de la UTN Facultad Regional Villa María con los que se transcribieron los datos de Regu. Los archivos no se suben al repositorio: son de la facultad y no se redistribuyen desde acá. Solo este README está versionado.

Los datos ya transcriptos están en [`../datos/`](../datos/). Para rehacer o revisar una transcripción, bajá el original:

| Documento | Dónde se publica |
|---|---|
| Plan de estudios ISI 2023 (imagen escaneada) | https://frvm.utn.edu.ar/static/assets/resources/plan_sistemas_2023.pdf |
| Plan de estudios ISI 2008 (se usa para las correlativas de las electivas) | https://frvm.utn.edu.ar/static/assets/resources/plan_sistemas_2008.pdf |
| Ordenanza 1549, Reglamento de Estudio de grado | https://frvm.utn.edu.ar/static/assets/resources/Reglamento%20de%20Estudio%20-%20Carreras%20de%20Grado%20-%20Ordenanza%201549.pdf |
| Ordenanza 1622, Reglamento de Estudio de pregrado | https://frvm.utn.edu.ar/static/assets/resources/Reglamento%20de%20Estudio%20-%20Carreras%20de%20Pregrado%20-%20Ordenanza%201622.pdf |
| Calendario académico 2026/27 | https://frvm.utn.edu.ar/media/calendario_academico/calendario_academico.pdf |
| Horarios de Ingeniería en Sistemas de Información | https://frvm.utn.edu.ar/media/horarios/sistemas.pdf |
| Planificaciones de cátedra (una por materia, con las condiciones de aprobación) | listado en https://frvm.utn.edu.ar/cultura-utn/planificaciones-catedra/ , archivos en `https://frvm.utn.edu.ar/static/assets/resources/planificaciones_catedra/<carrera>/<materia>.pdf` |
| Planes de las demás carreras (Civil, Electrónica, Industrial, Mecánica, Química, Administración Rural, tecnicaturas) | los aportó el usuario; se publican en https://frvm.utn.edu.ar/ |

Varios son imágenes escaneadas sin texto: se transcribieron a mano y quedaron marcados con `verificar` donde hubo dudas (ver [`../docs/investigacion.md`](../docs/investigacion.md)). Los datos oficiales los publica la facultad y pueden cambiar durante el año; la fuente de verdad es siempre autogestión.
